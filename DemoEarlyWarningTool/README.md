# Activity 2: Student Early Warning Tool Using KNIME

This repository contains the required output for Activity 2 in CS0065. The project uses KNIME Analytics Platform to predict student risk status from academic performance data.

## Project Files

- `DemoEarlyWarningTool.knwf` - exported KNIME workflow
- `student_performance_knime.csv` - dataset used by the workflow
- `Dancel_JamellaTracyL_KNIME_GitHub_Evidence.pdf` - evidence of project preparation and verification

## Algorithms

- Logistic Regression
- Random Forest
- Decision Tree

## How to Run

1. Download or clone this repository.
2. Import `DemoEarlyWarningTool.knwf` into KNIME Analytics Platform.
3. Configure the CSV Reader node to use the included `student_performance_knime.csv` dataset.
4. Execute all workflow nodes.
5. Open the Scorer nodes to review the evaluation results.
